Zap

Boost any webpage. Zap a stray element, recolor something, swap the font, or fix a label — saved per-site so it stays boosted on every visit. Inspired by Arc Browser's Boosts.

Boost tools

⚡ Zap

Remove any element — permanently, or just for this visit with Shift+click.

🎨 Recolor

Set an element's text or background color with a live preview, or recolor the whole page.

🔤 Font

Pick a preset or type any CSS font stack and preview it before saving.

✏️ Text

Rewrite a label's text. It re-applies even if the site's JavaScript redraws it.

🧩 Style

No-code sliders for size, weight, spacing, padding, corners, and more.

📜 CSS

A whole-site stylesheet editor for anything else. Click an element to insert its selector.

Install

  1. Download the latest zap-extension-v*.zip from the Releases page and unzip it.
  2. Open chrome://extensions in Chrome, Arc, Edge, or Brave and turn on Developer mode.
  3. Click Load unpacked and select the unzipped folder (the one containing manifest.json).
  4. Pin Zap from the extensions menu, open any page, and press Boost mode.

Zap makes no network requests — boosts live only in your browser's local extension storage. Read the privacy policy. MIT licensed.
